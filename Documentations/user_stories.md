## User Stories for Jyo Cho (Influencer)

1. Authentication & Profile Management
   - As Jyo, I should be able to log in and log out securely.
   - As Jyo, I should be able to update my profile (profile picture, bio) to reflect my brand identity.
2. Board & Image Uploading
   - As Jyo, I should be able to create multiple boards to organize my content for different themes.
   - As Jyo, I should be able to upload high-quality images to my boards with a title and description to engage my audience.
   - As Jyo, I should be able to delete or edit my uploaded images to maintain my brand’s consistency.
3. Engagement (Likes & Comments)
   - As Jyo, I should be able to receive likes on my images to gauge audience interest.
   - As Jyo, I should be able to moderate comments on my posts by deleting inappropriate ones.
   - As Jyo, I should be able to reply to comments (threaded comments) to engage in conversations with followers.
   - As Jyo, I should be able to track which of my posts receive the most engagement.

## User Stories for Arashita (Creative User & Developer)

1. Authentication & Profile Management
   - As Arashita, I should be able to log in and log out securely.
2. Board & Image Uploading
   - As Arashita, I should be able to create boards to organize my creative inspirations.
   - As Arashita, I should be able to upload images related to my creative projects, such as designs, artwork, or UI inspirations.
   - As Arashita, I should be able to delete or edit my uploaded images to refine my collections.
3. Engagement (Likes & Comments)
   - As Arashita, I should be able to like images to appreciate creative work from others.
   - As Arashita, I should be able to comment on images to discuss ideas or ask questions.
   - As Arashita, I should be able to reply to comments (threaded comments) to engage in discussions with creators.
   - As Arashita, I should be able to follow specific boards or users whose work inspires me.
