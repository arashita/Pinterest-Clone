DATABASE SCHEMA
1. User
Fields:
id (Primary Key)
username (Unique)
email (Unique)
password_hash
profile_picture (Optional)
bio (Optional)
created_at
updated_at

2. Board
Fields:
id (Primary Key)
name
description (Optional)
user_id (Foreign Key: Links to User table)
created_at
updated_at

3. Image
Fields:
id (Primary Key)
title
description (Optional)
image_url (URL to the image file)
board_id (Foreign Key: Links to Board table)
user_id (Foreign Key: Links to User table)
created_at
updated_at

4. Like
Fields:
id (Primary Key)
user_id (Foreign Key: Links to User table)
image_id (Foreign Key: Links to Image table)
created_at


5. Comment
Fields:
id (Primary Key)
user_id (Foreign Key: Links to User table)
image_id (Foreign Key: Links to Image table)
parent_comment_id (Nullable, Foreign Key: Links to Comment table for threaded comments)
content (Text)
created_at
updated_at

6. Threaded Comment (Reply to Comment)
Fields:
id (Primary Key)
parent_comment_id (Foreign Key: Links to Comment table)
user_id (Foreign Key: Links to User table)
content (Text)
created_at
updated_at

Relationships:
User ↔ Board: A user can create many boards.
User ↔ Image: A user can upload many images.
Board ↔ Image: A board can contain many images.
User ↔ Like ↔ Image: A user can like many images, and an image can have many likes.
User ↔ Comment ↔ Image: A user can comment on many images, and an image can have many comments.
Comment ↔ Comment (Threaded): A comment can have multiple replies (threaded comments).
